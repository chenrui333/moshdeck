01 / CONTINUITY

One place for the work.

Attach your Mac terminal and phone to the same tmux session. Your shell and long-running tools stay on the Mac.

02 / CONTROL

A real terminal.

Shell commands, full-screen tools, Escape and Ctrl-C. Use the native multiline composer for longer instructions.

03 / SIMPLICITY

Your own connection.

Ordinary SSH with verified host keys. The tested setup uses the official Tailscale apps. No MoshDeck account or cloud relay.

What to expect

A small utility, still taking shape.

Physical iPhone SSH/tmux access and recovery work. We’re testing longer sessions, mobile network transitions and everyday terminal tools. Expect rough edges; connection diagnostics are available from the terminal actions menu.

The current beta has one saved profile and one active terminal. Mosh transport and agent-specific features are not included.
